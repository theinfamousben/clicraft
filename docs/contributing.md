# Contributing

## Links

- [Full Guide](https://github.com/theinfamousben/clicraft/blob/main/CONTRIBUTING.md)
- [Issues](https://github.com/theinfamousben/clicraft/issues)
- [Pull Requests](https://github.com/theinfamousben/clicraft/pulls)

## Ways to Help

- **Report bugs** — Include steps to reproduce, OS, Node version
- **Suggest features** — Describe the problem it solves
- **Improve docs** — Fix typos, add examples
- **Submit code** — Fork, branch, PR

## Development Setup

```bash
git clone https://github.com/theinfamousben/clicraft.git
cd clicraft
npm install
npm link
```

Test changes with `clicraft` commands directly.
