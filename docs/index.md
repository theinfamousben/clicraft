# CLIcraft

A command-line Minecraft mod manager. Create instances, install mods from Modrinth, and launch the game—all from your terminal.

## Quick Start

```bash
npm install -g @bobschlowinskii/clicraft

clicraft create              # Create an instance
clicraft search sodium       # Find mods
clicraft install sodium      # Install mods
clicraft launch              # Play
```

## Requirements

- **Node.js** 18+
- **Java** 21+ (for Minecraft)

## Platforms

Linux, macOS, Windows
